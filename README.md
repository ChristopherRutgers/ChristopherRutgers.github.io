# Christopher Ramnauth — Portfolio

## Upload to GitHub

1. Unzip this download.
2. Upload `index.html` into the root of your GitHub Pages repository, replacing the old `index.html`.
3. Wait for GitHub Pages to finish deploying, then refresh your website.

The page is now self-contained: the profile photo, styles, resume, and redacted management project PDF are embedded in `index.html`. No assets folder or separate stylesheet is needed. Existing older assets can remain; this page does not depend on them.

Open `index.html` in a browser to preview. The download buttons save the embedded PDFs with descriptive filenames. Edit the visible text in `index.html` to update your portfolio; keep the long data URLs intact.

The management report has groupmates’ names redacted. The supplied resume and other contents of the project report remain unchanged.
